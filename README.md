# rag-faq-bot

Telegram-бот с RAG (retrieval-augmented generation): отвечает на вопросы по базе знаний, находя релевантные документы и передавая их модели как контекст — не выдумывает ответ и указывает источник.

Демо-тематика — FAQ по внутренней AI-платформе (доступ к API, модели, лимиты, ошибки, промптинг, поддержка), но подход применим к любой базе документов.

## Запуск
```bash
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
copy .env.example .env
```

Заполни `.env`:
- `BOT_TOKEN` — токен бота от [@BotFather](https://t.me/BotFather)
- `ANTHROPIC_API_KEY` — ключ Claude API

Проиндексировать базу знаний (нужно один раз и при каждом изменении документов в `documents/`):
```bash
python ingest.py
```

Запустить бота:
```bash
python bot.py
```

## Использование
Просто напиши боту вопрос — например «Что делать при ошибке 429?» или «Как получить доступ к API?». Бот найдёт релевантные фрагменты в `documents/`, передаст их модели как контекст и укажет источник в ответе.

## Как это работает
1. `ingest.py` — режет markdown-документы на чанки, считает эмбеддинги (sentence-transformers, локально, без внешнего API) и сохраняет в ChromaDB
2. `rag.py` — на вопрос находит топ-3 релевантных чанка, передаёт их Claude вместе с вопросом с инструкцией отвечать только на основе контекста
3. `bot.py` — принимает вопрос в Telegram, отдаёт ответ с указанием источника
