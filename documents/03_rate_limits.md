# Лимиты запросов

Базовый лимит на команду: 60 запросов в минуту и 50 000 токенов в минуту суммарно по всем моделям.

При превышении лимита API возвращает код ошибки 429 с заголовком `Retry-After` — там указано, сколько секунд нужно подождать перед повтором. Не делайте повторный запрос раньше этого времени, иначе счётчик лимита обнулится заново и ожидание увеличится.

Для батчевых задач (разметка данных, массовая обработка документов) используйте очередь `batch-queue` вместо прямых вызовов API — там лимиты выше (500 запросов в минуту), но ответ приходит асинхронно, через вебхук или опрос статуса задания.

Увеличение лимита для команды — заявка в тикет-системе, категория "AI Platform / Quota Increase", с обоснованием ожидаемой нагрузки. Рассматривается платформенной командой, обычно 2-3 рабочих дня.
