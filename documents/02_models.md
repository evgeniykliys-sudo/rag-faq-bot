# Поддерживаемые модели

Платформа проксирует три семейства моделей, выбор — параметром `model` в теле запроса:

- `internal-fast` — для коротких задач классификации и извлечения сущностей. Низкая задержка (~300 мс), самый дешёвый тариф.
- `internal-standard` — модель по умолчанию для большинства сценариев: суммаризация, ответы на вопросы, генерация текста. Задержка 1-3 секунды.
- `internal-vision` — единственная модель с поддержкой изображений во входных данных. Используется для задач, где нужно разобрать скриншот или фото.

Явно указывать версию модели не нужно — платформа сама направляет запрос на актуальную версию внутри выбранного семейства. Если нужна воспроизводимость ответов для тестов, зафиксируйте версию через параметр `model_version` (см. документацию API).

Не используйте `internal-vision` для задач без изображений — маршрутизация на неё стоит в 4 раза дороже `internal-standard` при сравнимом качестве текстовых ответов.
