# Рекомендации по составлению промптов

Используйте параметр `system` для задания роли и постоянных правил ответа — не дублируйте эти инструкции в каждом пользовательском сообщении, это тратит токены впустую при каждом запросе.

Для задач с предсказуемой структурой ответа (извлечение данных, классификация) используйте structured output / tool use вместо просьбы "ответь в формате JSON" внутри текста — модель реже нарушает формат, и не нужно парсить текст вручную.

Если модель галлюцинирует факты — проверьте, не отправляете ли вы вопрос без контекста, на который в принципе нет ответа в данных модели. В таких случаях используйте RAG-подход: сначала найдите релевантные фрагменты в базе знаний, затем передайте их модели вместе с вопросом и явно попросите отвечать только на основе переданного контекста.

Не передавайте персональные данные клиентов в промпт без крайней необходимости — даже во внутреннем контуре это фиксируется в логах платформы согласно политике безопасности.
